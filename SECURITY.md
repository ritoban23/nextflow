# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities by email to:
ankudutt101@gmail.com

If this project gets a dedicated domain mailbox, replace the address above with that mailbox and keep this document updated.

## Response Time

We aim to acknowledge reports within 48 hours.

## Disclosure Guidelines

1. Do not publicly disclose the issue before coordination.
2. Include clear reproduction steps, impact, and affected paths.
3. If possible, include a suggested mitigation.

## Secret Handling

1. Never commit secrets to the repository.
2. Use environment variables and CI secret stores.
3. Rotate exposed credentials immediately.
